## 计算链及时间

1. 力取原始 `pressure_force_sensor.sensor2`，沿用此前项目表格的换算约定 $T=0.0098\,\mathrm{sensor2}$ N。没有使用受限幅影响的 `thrust_data` 替代原始力读数，也没有分别对补偿前后去均值。本批固件的力转换仍未独立核实，因此换算结果保留这一条件。
2. 用户已明确确认：传感器轴向 $a_z$ 对应 `vehicle_acceleration.xyz[1]`，径向 $a_x$ 对应 `xyz[0]`，均取正号。`xyz[2]` 是接近−9.8 m/s²的重力轴，没有将其误当传感器轴向。
3. IMU使用原生 `timestamp_sample`，而不是根据力峰值调时延。发布时刻与采样时刻的中位差为0.405 ms。加速度按力通道原生时间戳线性插值，显示和评价窗口内均有原始IMU覆盖，不外推。
4. 固定安装下的静态重力投影与零偏按同一预扰动区间 $[t_{10}-3,t_{10}-0.5]$ s的加速度均值扣除。轴向基线为0.0359250813 m/s²，径向基线为0.2765257454 m/s²，因此实际输入为 $a_z=f_y-0.0359250813$、$a_x=f_x-0.2765257454$。这不是补偿后力信号的去均值，也不是逐点姿态重力重建；时变安装倾斜的影响未额外校正。
5. 严格计算 $\hat T=T-0.361a_z-0.033a_x$。1 s补偿前后均无额外滤波，保留全部力采样波动。原生IMU采样间隔中位值约0.049991 s（约20 Hz），插值仅用于时间同步，不能恢复未记录的高频加速度。
6. 来流仍取 $V_\infty=1.5|\omega_z|$，复用现用图8—12的0.35 s中值阈值检测流程。$t_{10}=170.097667$ s，$t_{90}=170.895018$ s，实测10%—90%段为 **0.797351 s**。全部通道只减同一个t10。
7. 显示区间为 $\tau\in[-3,4.797351]$ s，评价区间为 $[t_{10},t_{90}+3]$，即[170.097667,173.895018] s。灰色阴影仅覆盖 $\tau\in[0,0.797351]$ s，全部有效样本及峰值均保留。六轴新版共用[-12,4] N和4 N刻度间隔；同列上下共用相同时间范围。

## 1 s统计

| 指标（评价窗口内379个力样本） | 未补偿T | 式(23)离线补偿后T_hat |
|---|---:|---:|
| RMSE / N | 2.30535 | 3.90469 |
| 最大绝对输出 / N | 5.70360 | 10.33692 |
| 均值偏差 / N | 0.19049 | -2.03740 |

两者最大绝对输出均发生在 $\tau=0.136163$ s。该点 $T=-5.7036$ N，$a_z=12.41834$ m/s²、$a_x=4.55443$ m/s²，两个补偿项分别为4.48302 N与0.15030 N。因此：

$$\hat T=-5.7036-4.48302-0.15030=-10.33692\ \mathrm{N}.$$

这说明在当前正号定义下，正的轴向加速度补偿项进一步减小了已为负的原始输出。需要核对论文式(23)的坐标正方向、力传感器输出符号及其与本记录的安装对应关系；不能为了获得更平滑或更小的残差擅自改为加号。

电机PWM在显示区间内固定1000 μs，符合停转命令；rpm_raw仍有208/390个非零样本，最小值约−1250.87 rpm。因此记录属于停转指令工况，但严格机械停转状态不能仅凭该日志独立证明。本次未强制置零编码器读数。
